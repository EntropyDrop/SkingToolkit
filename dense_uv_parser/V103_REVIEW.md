## 为什么合成指标不能证明修复成功

合成验证 UV 损失从 0.2114 降至 0.0262，所属面准确率从 66.98% 升至 98.86%；这些改善没有转化成用户样例的正确最终 UV。

代码中可以确认的监督缺口：`v103_losses.py` 的 UV 索引来自渲染真值，`structured_uv_loss` 只统计 `counts >= 1` 且 `target > 0` 的格子。镜像项也只作用于有真值标注、可见的胡子对应格子。它没有直接监督最终推理链路生成的 UV alpha、错误路由和透明外层负样本；RGB 则继续沿用原来的取色和补全流程。真实样例仅用于开发回归，未进入梯度训练。

后续应优先完善最终 UV 占用、错位和跨面连接的监督，加入按身份隔离的真实 UV 标注，并统一训练评估与独立推理的执行设置。当前没有证据表明仅延长现有训练就能解决问题。
