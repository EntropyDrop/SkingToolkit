# v103 批量反馈后的泛化修订

## 已复现的原因

- `99LBZPR14PEYLZ69_edited.png` 是带麦克风的耳机、没有眼镜。v101 和最后解码器之前的前脸外层都只有麦克风的 3 格；旧 v103 最后解码器额外添加 `(40,12)、(41,12)、(45,13)` 三格，置信度为 0.844、0.918、0.900。最终颜色拟合保持 alpha，没有制造这些突起。
- `254NJBPVUEM759NA_edited.png` 的 v101 头部外层为 96 格。仅关闭 `reconcile_joint_head_geometry`，保持面路由时，v102 父流程从 59 格恢复到 96 格；关闭面路由却不能恢复。原清理把用于皇冠的逐格删除过程扩展到全部外层，以预测语义的重建误差为依据删去了 37 格。最后 UV 编辑还移除了刘海上缘并增加零碎格子。
- 旧 UV 编辑的二分类占用与语义分类独立。它能在语义分支预测 UV 0 类时新增外层，也能在预测外层头发时删除。UV 0 类在有标注的外层训练数据中对应空位；原图语义网络的 0 类仍表示弃权，不能简单把原图弃权阈值当作删除规则。
- 之前只有 64 个未重绘训练皮肤，程序化头部与少数反复查看的例子不能代表网站上的发型分布。两张新反馈图不加入梯度训练。

## 实现

`joint_head_geometry_mode` 默认仍为 `semantic_prune`，新实验设置 `disabled`，由最终学习分支处理头部占用。旧配置行为不变。

`FinalHeadUVDecoder.semantic_geometry` 默认关闭；开启时把编辑先验加入所有非空 UV 类的分数，同一个类别分布同时提供材质类别和外层存在概率。占用损失与语义损失均反向传播到这一决策，不再让两套分数各自决定。身体、无效 UV 和内层 alpha 保持原有约束。

新增 128 个训练、32 个验证的原始皮肤，不重绘 RGBA；另新增 32/8 个源身份，每个生成 bare/glasses/phones 三个版本，同一人物的头发、脸和胡子不变，只添加配饰。配对训练每 4 步加入一组三图，监督配饰带来的占用差异以及配饰之外应保持相同的区域。推理不读配对、标签、文件名或身份。

保留旧缓存为“经过旧清理的输入扰动回放”，新缓存使用关闭清理后的实际父流程。按内容哈希校验源身份划分；新旧原始纹理、程序化结构及新配对验证必须分开报告。预计共 544 个训练样本、136 个验证样本，分别来自 480/120 个源身份。已有 3 个真实训练身份保留其角色，其余真实图及两张反馈均为无梯度开发验证。
