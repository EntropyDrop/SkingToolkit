# v101：去背景、帽沿部件监督与材质保留

2026-09-06 已完成去背景模型专项微调、验收，再进行 v101 的 8,000 步续训；当前发布选中第 7,000 步权重。`v101_release.json` 固定解析器、去背景权重和配置的校验值。v100 提交 `b4718941a03a67d9fad7e28d0fd2bbb467b0d6f0`、原 v61/v101 权重及历史结果保留，v94 未参与。

原有 v61 网络保持冻结。头部配饰分支预测眼镜、帽子和外层头发；新增部件分支区分内层帽冠/色带、外层帽冠/色带与帽沿。数据包含环绕、前帽舌和非对称反例，跨面共享几何与材料。标签来自构造对象，不由颜色决定；未知原始内层头部不再作为语义反例回放。

可靠前景形状和 RGB 取色掩码分开。新增外层会覆盖原内层像素，因此最终头部 RGB 使用两视角的可见材质重建；alpha 和身体纹理不变。

在仓库根目录运行：

```bash
# 自动加载发布的 v101 和配套去背景模型，默认处理登记的 14 张图片。
bash dense_uv_parser/batch_infer.sh

# 处理指定双视角拼图。
bash dense_uv_parser/batch_infer.sh --inputs /absolute/path/image.png

# 再次训练时指定新目录，防止覆盖。
OUTPUT_DIR=dense_uv_parser/runs/my_v101_retrain bash dense_uv_parser/run_v101_retraining.sh
```

新的训练入口使用 8,000 步、batch 8、学习率 2e-5、每 1,000 步验证，仅训练配饰和部件分支。`run_v101_training.sh` 保留为初版 20,000 步训练配方。旧通用 `run_infer.sh` 仍有自己的参数；标准使用与验收入口为 `batch_infer.sh`。

去背景测试按归一化皮肤身份隔离；v101 程序化测试按来源文件划分。真实帽子和眼镜是开发回归，不参与梯度训练，也不是独立泛化测试。存储层分歧指标不等同于完整语义误报率。
