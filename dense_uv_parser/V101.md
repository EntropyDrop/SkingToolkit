# v101：头部配饰语义监督

v100 基线已先提交在分支 `v100`（`b4718941a03a67d9fad7e28d0fd2bbb467b0d6f0`）。v101 从原始 v61 权重构建，冻结原有网络，单独训练新增的头部配饰分支。v94 未参与。

## 修复内容

- 用头部 224×224 裁剪、冻结的 SigLIP2 特征和可训练解码器，预测眼镜、帽子、外层头发。监督标签来自绘制对象的身份，并经渲染器投影到原图像素；颜色不决定标签。当前每个角色、每个类别只有一个对象身份，不是通用多实例分割器。
- 扩充深色镜框、鼻桥、半框、空镜框、不同镜片颜色与阴影。类别损失、Dice、边界差分和跨 UV 接缝的结构损失共同监督完整性。原始皮肤中确认属于内层的头部像素用于反例回放；未标注的外层像素不强行分配语义类别。
- 推理从高置信度配饰位置出发，保留同一预测类别相连的区域。配饰证据可以修正旧模型的内层判定，并避免被局部格子投票和最少采样像素规则再次删除。背景、头部几何和轮廓约束仍生效。
- 修复内层补全从外层独有颜色取样的问题。训练验证和新版批量推理共用 `accessory_pipeline.py`，配置随检查点保存。
- 批量输出按输入路径和内容、权重内容、配置及代码计算指纹。完整输出原子落盘；旧目录、同名图片、训练期间更新 best.pt 不会造成结果来源混淆。

## 运行

以下命令在 `/home/ds/llms/SkingToolkitDev` 下执行：

```bash
# 正式训练；先准备经过验证的 runs/v101_seed/seed.pt。
bash dense_uv_parser/run_v101_training.sh

# 使用检查点内嵌配置，推理登记的 14 张回归图片。
bash dense_uv_parser/batch_infer.sh

# 推理指定文件。
bash dense_uv_parser/batch_infer.sh --inputs /absolute/path/image.png
```

`run_v101_training.sh` 默认再训练 20,000 步、batch size 8、学习率 5e-5、每 1,000 步验证。`RESUME`、`OUTPUT_DIR`、`STEPS`、`EVAL_EVERY` 可通过环境变量覆盖。这里的 warm start 只恢复模型并启用新优化器；不是精确恢复优化器状态。

训练目录禁止覆盖。正式训练先重新验证种子，通过后保存初始 best.pt，再开始更新。latest.pt 保留最新进度，best.pt 仅在满足所有验收条件且验证评分提高时更新；训练结束后对选中的 best.pt 运行留出的测试来源。

旧 `run_infer.sh` 保留兼容性，并已绑定当前仓库，但仍有自己的命令行默认参数。v101 的标准验收与使用入口是上面的 `batch_infer.sh`，不要混用两套参数比较结果。

## 证据和边界

- `config.json` 记录原始 v61、warm start、代码的校验值，提交号、参数、有效推理配置和数据来源数量；`source/` 保存代码快照，`source_splits.json` 保存训练、验证、测试文件列表。
- 验证包含 64 个程序生成皮肤（交替原始与外观扰动）、64 个原始皮肤的新增外层误报检查，以及用户提供的眼镜开发回归图。
- 程序生成对象的完整率表示单个可见视图中某类配饰至少 95% 像素被保留。UV 外层存在率和最终 RGB 误差另外记录。
- `TWRLRRTHQP2UV368_edited` 的眼镜轮廓由助手目视描绘，忽略 2 像素边界带。它参与开发与检查点准入，不用于梯度训练，**不能作为独立泛化测试**。绿色镜片统计只是该样例的诊断指标。
- 当前验收条件：生成对象 precision ≥90%、recall ≥75%、可见对象完整率 ≥25%；原始皮肤新增外层误报率 ≤3%；开发图眼镜语义 precision ≥85%、整副眼镜外层保留率 ≥90% 且比冻结 v61 提升至少 15 个百分点。
- 这次新增语义能力集中在头部配饰。服装、身体和任意新物体的语义并未完整解决，仍需要更多人工标注的真实图像及独立实测集。
