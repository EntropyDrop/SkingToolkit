# 01 问题定义与背景

## 1.1 这个系统在解决什么问题

Dense UV Parser 的任务可以概括成一句话：

> 输入两张或多张固定视角的 Minecraft 角色渲染图（如正面、背面），输出一张
> 64×64 的 RGBA 皮肤图集（skin atlas / UV map），使该图集在相同相机
> 设置下通过 3D 渲染器渲染回去时，能高保真还原输入的渲染图。

这是一个典型的**逆渲染（inverse rendering）**问题：

```text
正向： 皮肤图集(64×64)  ──► 可微渲染器(3D) ──► 渲染图(256×512)
逆向： 渲染图(256×512)  ──► 解析网络 + 假说检验 ──► 皮肤图集(64×64)
```

正向过程（`SkingToolkit/renderer.py` 中的 `DifferentiableRenderer`）
是完全已知的：给定一张皮肤纹理和固定的相机/姿态/光照约定，用可微的
纹理采样（`F.grid_sample`）把图集映射到屏幕上。逆向过程则是本系统要
学习的：给定屏幕上每个像素的颜色，推断它来自图集上的哪一个纹素
（texel）、属于哪一层（内层基础皮肤 / 外层立体装饰）、哪个身体部位、哪个面。

## 1.2 为什么这不是一个平凡的问题

从一张渲染图还原纹理，看起来只是"把像素抄回去"，但实际上有四个
本质困难：

**1. 像素是"分层"的，且层边界存在混合。** 皮肤图集上的 alpha 是
**二值**的——数据集把半透明像素直接置为全不透明，所以不存在"半透明纹素"。
但渲染是"外层盖内层、内层盖背景"的合成：一块不透明外层纹素会把内层
**完全遮住**；同时渲染器默认用**双线性采样**（`renderer.py` 的
`sampling_mode="bilinear"`），在内外层交界处会产生抗锯齿过渡色。
因此逆向过程不能盲目"直接取色"，而必须做准确的分层路由与中心加权投票。

**2. 遮挡与内外层歧义（Outer vs Inner Ambiguity）。**
在单张 2D 渲染图上，一块颜色（例如头部的黄色或者卫衣领口的深蓝色）
在 2D 投影上既可能是贴在身体基底上的平铺颜色（内层基底，Scale=1.0），
也可能是向外浮空的立体饰品（外层立方体）。
在 Minecraft 的长方体几何膨胀机制中，各轴向的缩放比由绝对外扩厚度决定：
- **头部（Head，8×8×8）**：外层每面外扩 0.5 格（总长 $+1.0$），缩放比为 $\text{scale} = \frac{x + 1.0}{x} = \frac{9}{8} = 1.125$；
- **躯干与四肢（Body & Limbs）**：外层每面外扩 0.25 格（总长 $+0.5$），缩放比为 $\text{scale} = \frac{x + 0.5}{x}$（例如宽度 $x=8$ 时为 1.0625，高度 $x=12$ 时为 1.0417，厚度 $x=4$ 时为 1.125）。
如果把领口衣服误判为头部外层，在 3D 渲染中它就会变成一块悬空面罩挡住下巴；
如果把皇冠误判为内层，皇冠顶部的锯齿轮廓就会丢失。

**3. 视角盲区与信息丢失。**
即使有两个视角（front_left, back_left），角色的某些死角（如两腿内侧、
腋下、下巴底面）仍然处于视线遮挡的**几何盲区**。
对于内层基础皮肤，必须利用人体左右对称性和同部位临近填充进行保底；
对于外层装饰，看不见就必须保持**100% 纯净透明（alpha=0）**，严禁凭空脑补。

**4. 视角歧义（view ambiguity）。**
正面和背面渲染在很多皮肤上是对称或相似的。模型必须显式地以
**视图索引（view id）** 和 3D UV 空间投影为条件，建立跨视角的空间对齐。

## 1.3 系统的设计哲学

为了应对上述困难，系统采用了"**几何锚定 + 3D UV 空间融合 + 假说检验 + 确定性内层保底**"
的架构：

1. **固定几何锚定（Geometry-Anchored）**：Minecraft 角色由固定
   cuboid（长方体）组成（头、躯干、双臂、双腿，每部分 6 个面），
   其 UV 布局是公开且固定的（见 02 章）。屏幕像素到 UV 坐标的映射
   由渲染器几何表确定，网络不需要学部位回归，只需专注在分层路由与特征提取。

2. **3D UV 空间跨视角融合（UVMultiViewSpatialFusion）**：
   将来自不同视角（例如正面与背面）的 2D 卷积特征，直接通过 3D 射线反向投射到
   统一的 64×64 UV 空间进行 360° 全局聚合，再反向广播回各个视角，
   让网络在特征层面就拥有了完整的 3D 空间一致性认知。

3. **假说检验与可微裁决（Analysis-by-Synthesis）**：
   对于模棱两可的外层饰品区域，系统生成“纯内层”与“外层立体”两组 UV 假说，
   调用 `DifferentiableRenderer` 进行实时重渲染，对比原图残差。
   只有当外层假说能够显著改善 3D 轮廓与多视角重投影时才保留外层，
   从物理机制上杜绝了下巴被误遮挡等外层伪影。

4. **极简内层确定性修复（Pure Inner-Only Inpainting）**：
   内层仅针对物理死角盲区（如腋下、裆下）做左右镜像与同部位近邻填充；
   外层严格遵循“未观测 = 透明”，绝不进行复杂图扩散或脏色脑补。

## 1.4 问题分解：系统要预测什么

对每个渲染像素，系统预测：
- **前景/背景**（foreground/background）；
- **路由角色（route role）**：直接可映射的内层（inner）、直接可映射的
  外层（outer）、或次级/更深表面（secondary）；
- **精确的渲染器表面槽位（surface slot）**：用于把穿透/次级像素映射到正确图集；
- **该路由正确的概率**（置信度头，用于推理时的门控）；
- **全局 3D 外层占有率（Outer UV Occupancy）**：在 64×64 图集上直接预测外层是否为实体。

## 1.5 学习本系统能收获什么

- **计算机图形学**：UV 映射、纹理图集、alpha 合成、可微渲染、Analysis-by-Synthesis 假说检验。
- **深度学习**：多视角特征融合、3D UV 空间特征投影、视觉-语言模型（SigLIP2）先验。
- **工程系统**：特征缓存（mmap）、纯张量确定性修复、可微验证门控。

## 本章要点

1. 任务 = 逆渲染：从固定视角渲染图高保真恢复 64×64 皮肤图集。
2. 困难 = 分层遮挡、内外层歧义、盲区信息缺失、视角对抗。
3. 解法 = 几何锚定 + 3D UV 跨视角融合 + Analysis-by-Synthesis 可微假说检验 + 极简内层盲区修复。
