# v104：学习头部跨面连续性，扩大原生纹理覆盖

2026-09-07 已完成训练和结果检查。6000 步训练中按验证集选取第 5000 步。相对已修订 v103，可见头部和配饰测试有所改善，但原生皮肤全头部 IoU 基本持平，未观察到的头底面退步。因此保留为经过复核、有明确局限的 v104 候选，没有替换全局默认模型或全量网站结果。

起点：v103 分支提交 `9b7adc5`，模型 `runs/v103_generalization_20260907/candidate_risk_1000_beard_protected/parser.pt`，SHA256 `c2753056f05d0772aa38ad6fe37aaa14c4c90034d4886ed2d75bd1c0644d3165`。v104 在独立分支上开发；保留 v103 模型及输出。

改进采用四组措施：

- 以原始 UV 身份归一化内容去重后新增 448 个训练身份：384 个原生纹理身份，以及 64 个无配饰/眼镜/耳机配对身份。新增验证 80 个身份、测试 80 个身份，测试清单在训练前固定，不供 checkpoint 选择。新图经过当前部署父流程（关闭误删清理、只对胡子进行语义面校正），旧缓存明确作为父流程错误扰动回放。半数新增训练身份加入不改变几何的光照、模糊和颜色扰动。
- 在最终 UV 解码器增加可学习的头部邻域模块。分别汇聚同一面和真实立方体接缝两侧的特征；不按 PNG 中相邻岛块连边，不把相邻格子强制设为相同。新增模块零输出初始化，迁移 v103 时预测逐位一致。
- 增加由真实 UV 监督的边界损失，以及按立方体邻域生成的整块缺失/多余区域增强。损失同时学习连续区域和真实断开边界，避免无条件填洞。已有语义占用统一、眼镜/耳机配对损失、胡子材质关系、耳机颜色保护继续保留。

新增 `mask_unknown_relations` 训练开关：没有语义标注且颜色不冲突的关系不当作负例；双方可见、目标颜色不同的关系仍是明确的负例。只有语义标注支持时才建立正例，避免仅凭相同颜色推断胡子关系。旧 checkpoint 的默认训练行为不变。

保留原来的三个有局部标注的真实训练身份。标注区使用原有明确目标，其他区域仅将已审查的 v103 输出作为一致性教师，不宣称为人工真值。两张新眼部/头发反馈图仍不进入梯度训练。真实开发集和新测试身份均不参与训练采样。
