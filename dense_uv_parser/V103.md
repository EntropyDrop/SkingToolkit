## 数据和训练

- 50% 新结构样本：六面物理镜像对应的对称胡子、明确不对称胡子、内外层对齐的混合胡子，以及平面头发、不带顶面的刘海、局部包顶刘海和完整外层头发。
- 50% v102 联合语义、眼镜/耳机、帽子/皇冠及真实纹理头发的合成回放。沿用 train/validation/test 源身份隔离；验证身份以前用过，不是全新独立真实测试集。
- 每个样本渲染 front_left、back_left、front_right、back_right，形成两个正背视图对。
- 训练 v102 的 head_semantics_head，包括所属面的分类器。其余父模型参数保持逐张量完全相同。
- 损失为原联合像素分类 + 0.4 所属面分类 + 0.8 UV 结构项。UV 项按格子而非投影面积计分，包含有明确标注时才启用的左右对应和混合层对应约束。

UV 项使用渲染真值的像素到 UV 对应，**不是**对整个离散后处理链路求导，也没有训练 RGB 颜色解码器。因此仍必须检查最终自动导出的 UV，不能用合成损失降低替代真实结果验收。

用户的 edited 输入、旧版 result、上轮参考修正结果及其标注均不进入梯度训练。该实例保留为开发回归；自动推理没有文件名匹配或强制镜像操作。

## 运行

```bash
bash dense_uv_parser/run_v103_training.sh
```

默认训练目录 `dense_uv_parser/runs/v103_uv_structured_20260906`，6000 步、batch 4（每步 16 个视图）、初始学习率 5e-5。第 200 步及每 1000 步保存 checkpoint、合成验证与真实开发集自动 UV。目录包含源码快照、父模型和数据划分哈希、PID、训练状态、优化器状态和最终 UV 对称性检查。

```bash
OMP_NUM_THREADS=4 /home/ds/miniconda3/envs/sking-v61-worker/bin/python \
  dense_uv_parser/run_local.py test_v103
```

6 项测试覆盖六面胡子对称、混合层材质对应、没有强制头顶边的刘海、不对称反例、身体不变及 UV 损失梯度。正式运行前执行 4 步 GPU 冒烟训练并验证冻结参数。

## 候选与发布

训练结束仅表示候选生成。`train_v102.real_review` 对未经参考修正的模型输出运行既有 17 个开发例，并记录 `annotated_uv_review`：胡子逐层透明度/颜色镜像差异及指定刘海区域相对参考的 alpha 差异。

候选必须通过本例的 UV 检查、多视图轮廓检查，以及皇冠、鼻子、耳机、眼镜、帽沿等既有回归后才能作为已验证发布。v101/v102 发布权重和原数据目录输出不因开始训练而替换；不把手工修正图片充当模型预测。
